# Kobo KOReader Migration

An offline macOS tool for migrating KOReader, ebooks, reading data and fonts between Kobo readers.

This repository is being prepared for its first public version. The complete script, detailed documentation, fixture tests and contribution workflow are available on the [feature/public-release branch](https://github.com/gh-slee/kobo-koreader-migrate/tree/feature/public-release) pending human review and sign-off.

The tool is experimental. Physical-device acceptance is pending; test fixtures do not establish hardware compatibility. Runtime features use ordinary standalone code without an LLM or AI service.

MIT licensed; see [LICENSE](LICENSE). Never upload device backups, books, credentials or reading history to this repository.
